# Contributing

Preserve deposited inputs, frozen rankings and audit history. Never invent values or modify scientific artifacts to pass tests.

1. Install pinned dependencies as documented in README.
2. Run source-only Python/API tests, TypeScript and production build.
3. For data-dependent changes, install the verified research bundle and run the full scientific/API/browser suite. Report missing data explicitly.
4. Include rationale, executed commands, test results, provenance and limitations in the pull request. Scientific changes require isolated reruns and input hashes, model/contrast, FDR family and annotation documentation.

Label synthetic software fixtures; never include them in research figures or APIs. Do not add credentials, dependencies, raw data or archives to Git. Mouse cross-model agreement is not clinical validation. Run `python scripts/repository_audit.py` before proposing publication.

Contributions must be compatible with LICENSE; separately document third-party data rights. Public release and data publication require the maintainer's approval.
